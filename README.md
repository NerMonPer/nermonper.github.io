# Nerea Montes-Pérez — personal website

A Quarto website for research, publications, CV and creative work. The editable pages are the `.qmd` files, the visual styles are in `styles.css`, and the published GitHub Pages output lives in `docs/`.

## Edit and publish

1. Install [Quarto](https://quarto.org/docs/get-started/).
2. Edit the relevant `.qmd` file and preview with `quarto preview`.
3. Run `quarto render` to regenerate `docs/`.
4. Commit both the source changes and the regenerated `docs/` files. GitHub Pages can serve the `docs/` directory from the main branch.

The artwork in `assets/` is decorative. Replace or supplement it with personal photographs or illustrations when available. The former photography URL redirects to the creative work page, so old links still work.
